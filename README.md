## 💎 About ATS Fashion & Fabrics

ATS Fashion & Fabrics is a modern B2B lingerie and intimate apparel manufacturer headquartered in Ghaziabad, Delhi NCR, India. We partner with emerging fashion labels, D2C lingerie brands, and global retailers to turn intimate apparel concepts into production-ready collections with rigorous consistency, precision cup molding, and fine seam engineering.

### 👙 Product Lines
- **01 — Bras**: T-shirt, wired, wire-free bralettes, plunge, push-up, sports & nursing silhouettes with ergonomic memory-foam cup molding.
- **02 — Panties**: Bikini, hipster, thong, boyshort, high-waist & laser-cut seamless briefs with 100% organic cotton gussets.
- **03 — Lingerie Sets**: Coordinated luxury lace sets, bridal collections, strapping details, and matched satin combinations.
- **04 — Seamless Wear**: 3D circular knit and stitchless bonded technology for zero irritation and smooth body contours.
- **05 — Shapewear**: Targeted compression bodysuits, high-waist tummy control briefs, and thigh sculptors with anti-roll silicone engineering.
- **06 — Nightwear**: Satin slips, modal lounge sets, camisole shorts, and robes tailored with french seams and fluid drape.
- **07 — Custom Lingerie**: Tech-pack interpretation, rapid 3D pattern grading, bespoke tooling, and custom cup molding.
- **08 — Private Label & OEM**: Turn-key brand solutions with custom woven labels, heat-transfer care labels, barcode hangtags, and FSC-certified eco packaging.

## 🏛️ Architecture & Tech Stack

- **Core**: Semantic HTML5 with Schema.org JSON-LD Structured Data (`Organization`, `LocalBusiness`)
- **Styling**: Vanilla CSS with modular design tokens, editorial typography scale (*Cormorant Garamond* + *Plus Jakarta Sans*), and glassmorphism backdrop blurs.
- **Logic**: Vanilla ES6+ modules for navigation, interactive product spec drawer, material studio, and B2B RFQ engine.
- **Build System**: Vite 5 for instant hot reloading and optimized production bundling.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000/](http://localhost:3000/) in your browser.

### 3. Production Build
```bash
npm run build
```
The compiled, minified bundle will be generated in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
